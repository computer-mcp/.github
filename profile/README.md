**Wherever you chat, your computer is there.**

**聊天在哪，你的电脑就在哪。**

ChatGPT can read and write code and run commands right on your computer, and use your
command-line tools, MCP, Skills and Computer Use; when needed, it hands the work to
Codex, Claude Code or Cursor. You set the permissions for each computer.

[Get started](https://computer-mcp.github.io/) ·
[Product and downloads](https://github.com/computer-mcp/computer-mcp) ·
[Documentation](https://github.com/computer-mcp/computer-mcp/tree/master/Documentation)

| Repository | Role |
| --- | --- |
| [Computer MCP](https://github.com/computer-mcp/computer-mcp) | macOS App that connects ChatGPT to your computer |
| [Website](https://github.com/computer-mcp/computer-mcp.github.io) | Product guide, verified downloads and plugin catalog |
| [Codex](https://github.com/computer-mcp/plugin-codex) | Codex execution and protocol inspection |
| [Computer Use](https://github.com/computer-mcp/plugin-computer-use) | Native desktop observation and actions |
| [Claude Code](https://github.com/computer-mcp/plugin-claude) | Claude Code CLI and streaming MCP adapter |
| [Cursor](https://github.com/computer-mcp/plugin-cursor) | Cursor Agent CLI and ACP integration |
| [Swift Format](https://github.com/computer-mcp/plugin-swift-format) | Verified Swift formatting and linting |
| [TRAE](https://github.com/computer-mcp/plugin-trae) | TRAE sessions through ACP; repository access required |
| [Apple CLI](https://github.com/computer-mcp/apple-cli) | A local macOS CLI and MCP server for Apple apps |
| [Homebrew Tap](https://github.com/computer-mcp/homebrew-tap) | Install Computer MCP and Apple CLI with Homebrew |

The App requires macOS 14 or later. Vendor runtimes and accounts have their own
requirements. Integrations retain vendor ownership and do not imply endorsement.

The [MCP Swift SDK fork](https://github.com/computer-mcp/swift-sdk) retains its
upstream SDK identity and independent technical scope.

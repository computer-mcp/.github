# Computer MCP

**Let ChatGPT use your local tools.**

**让 ChatGPT，用上你的本机工具。**

Direct, local, composable, multi-computer and governed. Connect ChatGPT or another
compatible MCP client to registered tools on your computers. Combine typed
capabilities, CLI, MCP, Skills and Computer Use; use Codex as an optional
integration. Each host retains its own workspaces, policy, approvals and audit.

The App requires macOS 14 or later. Vendor runtimes and accounts have their own
requirements. Integrations retain vendor ownership and do not imply endorsement.

The [MCP Swift SDK fork](https://github.com/computer-mcp/swift-sdk) retains its
upstream SDK identity and independent technical scope.

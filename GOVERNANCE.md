# Governance

Computer MCP has a single maintainer. Xudong Xu is the legal copyright holder;
`@showxu` is the public GitHub identity used for repository ownership and
`CODEOWNERS`.

The maintainer reviews and merges every change, decides releases and sets
repository policy. Changes to execution, authorization, credentials or transport
security receive the closest review.

Each repository owns its own decisions and rules:

- accepted technical decisions in `Documentation/Decisions/`, with current
  truth in `Documentation/Architecture/`;
- version and release rules in `Documentation/Architecture/VersioningAndRelease.md`,
  or its README where it has none.

[MAINTENANCE.md](MAINTENANCE.md) holds the conventions all repositories share.

# Support

Support is best effort for reproducible defects in the latest release of each
component. There is no guaranteed response time or paid support.

## Where to ask

| Topic | Repository |
| --- | --- |
| Computer MCP App, CLI, connections, configuration and the MCP Swift SDK fork | [computer-mcp](https://github.com/computer-mcp/computer-mcp/issues) |
| A first-party plugin | The plugin's repository, such as [plugin-codex](https://github.com/computer-mcp/plugin-codex/issues) |
| Apple CLI | [apple-cli](https://github.com/computer-mcp/apple-cli/issues) |
| Homebrew installation | [homebrew-tap](https://github.com/computer-mcp/homebrew-tap/issues) |
| Website and plugin catalog | [computer-mcp.github.io](https://github.com/computer-mcp/computer-mcp.github.io/issues) |

Report security issues privately as described in [SECURITY.md](SECURITY.md),
not in a public issue.

## Useful details

Include the component and its version, the macOS version, the Computer MCP
version and MCP client when relevant, the steps that reproduce the problem, and
the failing command or tool call. Remove secrets, tokens and private tool output
from configuration, logs and diagnostics before attaching them.

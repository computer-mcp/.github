# Computer MCP organization profile

`profile/README.md` is the public organization entry point. Shared artwork and
stable copy are imported from the main repository's canonical brand delivery.

Run `python3 Scripts/check-brand.py` to verify the lock. To update identity, use
`python3 Scripts/brand.py sync ../.github` from the main Computer MCP checkout,
then commit the synchronized delivery and profile. Integration names are plain
text; repository visibility and upstream ownership remain independently owned.

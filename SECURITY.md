# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately with **Report a vulnerability** on
the affected repository's Security tab. Do not open a public issue, discussion
or pull request for a suspected vulnerability. If you are unsure which
repository is affected, report it to
[computer-mcp](https://github.com/computer-mcp/computer-mcp/security/advisories/new).

Include:

- the affected component and its version or commit;
- steps to reproduce;
- expected and actual behavior;
- the security impact;
- relevant logs or payloads with secrets removed.

Security fixes are made for the latest release of each component.
